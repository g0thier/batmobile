# Documentation Batmobile

Ce dossier contient le site Docusaurus utilisé pour documenter le projet Batmobile.

## Installation

```bash
npm install
```

## Développement local

```bash
npm run start
```

## Build

```bash
npm run build
```

## Contenu

- `docs/` contient les pages de documentation en français.
- `src/pages/` contient l’accueil du site.
- `src/components/` contient les blocs réutilisables de la page d’accueil.
