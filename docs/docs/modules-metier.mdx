# Modules métier

Le code applicatif est organisé autour de quelques modules métier bien identifiables. Cette page sert
de passerelle entre la documentation et les écrans réellement exposés par l’application.

## Authentification

- Connexion par email et mot de passe.
- Réinitialisation de mot de passe.
- Déconnexion automatique de l’espace protégé si la session n’est plus valide.

## Quiz

Les quiz connus par le catalogue sont:

- Théorie X-Y
- Identité Pro
- Besoins de Maslow
- Autodétermination
- Attentes
- Équité
- Besoins acquis
- Mimétisme

Chaque quiz dispose de sa page de lancement et de sa page de statistiques associée.

## Historique

La page d’historique agrège les sessions à faire, en cours ou terminées. Elle permet:

- de reprendre une session active;
- d’ouvrir les statistiques d’une session terminée;
- de lire le statut et les dates de suivi avec un affichage adapté au mobile.

## Succès

Le module succès transforme l’activité utilisateur en repères visuels:

- nombre de questions répondues;
- jalons de progression;
- cartes de succès;
- indicateurs d’assiduité et d’amélioration.

## Profil

Le profil regroupe les informations utilisateur et sert de point d’accès aux réglages liés au compte.
