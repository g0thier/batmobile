# Batmobile

Batmobile est l’application compagnon mobile du projet Data-Driven. Cette documentation rassemble
le contexte produit, les choix techniques et les repères utiles pour contribuer au projet sans
avoir à relire tout le code à chaque fois.

## Ce que couvre cette documentation

- La vision produit et le périmètre actuel du projet.
- Le démarrage local de l’application Angular et du site Docusaurus.
- L’architecture technique côté routes, services et intégration Firebase.
- Les modules métier visibles dans le code: quiz, historique, succès, profil et authentification.
- Les repères de contribution pour garder l’ensemble cohérent.

## Parcours conseillé

1. Lire la [vision produit](./vision-produit) pour comprendre le positionnement de Batmobile.
2. Passer par le [démarrage local](./demarrage-local) pour lancer l’app et la doc.
3. Consulter l’[architecture technique](./architecture-technique) pour comprendre le flux applicatif.
4. Explorer les [modules métier](./modules-metier) pour relier la doc au code.
5. Terminer avec la [contribution](./contribution) si tu prépares une modification.

## Résumé rapide

- Frontend Angular 20 avec Ionic 8.
- Authentification, données et fonctions basées sur Firebase.
- Navigation mobile structurée autour d’un shell à onglets.
- Quatre entrées métier principales: Quiz, Succès, Historique et Profil.
